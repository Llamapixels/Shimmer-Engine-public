The community feedback update: edit scenes right on the world map, plus a long list of fixes and features from your reports.

- Edit scenes on the world map like GB Studio: the selected scene is the full scene editor in place, with the other scenes around it. The map keeps its zoom and scroll when you go to the scene view and back.
- 32 actors per scene (was 16), ceiling slopes, Show Emote, a Top Down hookshot, and the grapple can reel actors in or fly you to them.
- Menus can sit anywhere (top right like Pokemon, sides, center, custom) with their own open / close animation and cursor styles.
- Searchable sprite / actor / state pickers, multi-select events, duplicate / copy / paste scenes, scene list sorting, listen buttons for sounds and a color-coded build log.
- Fixes: animated tiles in grouped scenes, long Draw Text, transparency with lights, portraits under tint and lights, tint / light popping in after fades, event dragging and folding, speech bubble previews and Change Scene's Pick button.

Existing projects: On Init's instant events (tint, light, variables, positions) now run before a scene fades in. Saves from versions before 0.6.1 don't load. Rebuild ROMs after updating.

Installers: Windows x64, Linux x64 (AppImage and deb), and macOS Apple Silicon.
